# Reference Pattern Library

This file is a reasoning reference for the agent. It is deliberately structural rather than a set of copy-paste templates.

## Pattern families

### 1. Editorial
Hierarchy comes from heading scale, small caps, spacing and short labels.

Use for:
- profile
- history
- mailbox
- informational screens

### 2. Dashboard
Hierarchy comes from grouping and numeric emphasis.

Use for:
- marketplace
- statistics
- economy
- analytics

### 3. Utility
Hierarchy comes from explicit actions and compact state labels.

Use for:
- settings
- commands
- administration
- configuration

### 4. Detail + action
One object dominates; actions sit beside/below the detail.

Use for:
- item details
- purchase confirmation
- upgrade screen

### 5. Progressive flow
Only the information needed for the current step is emphasized.

Use for:
- creation wizards
- onboarding
- setup flows

### 6. List + filter
Repeated units are intentionally compact, with a separate filter/category area.

Use for:
- auctions
- quests
- players
- rewards

### 7. Status console
State is dominant; actions are secondary.

Use for:
- cooldowns
- machines
- systems
- live events

### 8. Comparison
Two or more states are placed in direct relationship.

Use for:
- upgrades
- item comparison
- price comparison

## Important

These patterns are not visual templates. They are information architectures. The agent must select a pattern and then create plugin-specific typography, colors, icons, copy and composition.
