# Command Tree Template

```text
/<root>
  help [page]
  list [filters]
  info <resource>
  create <name> [options]
  copy <resource> <new-name>
  edit <resource> <property> <value>
  action <resource> <trigger> <operation> ...
  remove <resource>
```

Replace the example branches with the architecture justified by the target project. Do not copy branches that do not apply.
